# Samyam Poudel — Personal Marketing Website

A modern two-page personal marketing/portfolio website for Samyam Poudel, a Global AI Convergence student at Seoil University.

## Pages
- `index.html` — Home, About, strengths, vision, contact
- `projects.html` — Projects, skills/toolkit, career vision

## Tech
HTML5, CSS3, vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or use any static server.

## Deploy
This is a static site and is ready for GitHub Pages, Vercel, Netlify, or another static host.
